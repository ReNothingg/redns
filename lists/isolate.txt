# Имена, которым нельзя делить соединение с соседями по домену (proxy.isolate в конфиге).
# Нужны, когда поддомен живёт у другого хостера, чем основной сайт, а сертификат
# основного сайта покрывает и его: все имена идут через один IP прокси, и Chrome шлёт
# запросы к поддомену по уже открытому HTTP/2-соединению основного сайта.
# Когда устройство спрашивает адрес такого имени, сервер закрывает его соединения
# с сайтами, чей сертификат подходит и этому имени, и браузер открывает новое.

# OpenAI: openai.com и platform.openai.com на Cloudflare с сертификатом *.openai.com,
# а эти живут на Vercel и Azure. Cloudflare отвечает на них Error 1016.
full:developers.openai.com
full:cdn.openai.com
full:status.openai.com
full:cookbook.openai.com
